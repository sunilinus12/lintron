# ⚡ Lintron

> Next-Gen Network Debugger & Chaos Engineering Tool for React Native & Expo.

Lintron provides real-time API monitoring, request interception/breakpoints, and dynamic network chaos engineering (2G, 3G, 4G, Subway/Metro fluctuations, and offline testing) with **zero native code changes**.

---

## 🌟 Highlights

- **⚡ Zero Configuration**: Works instantly with Expo Go, Bare React Native, iOS Simulator, Android Emulator, and physical devices.
- **📉 Network Chaos Engine**: Simulate real-world conditions like Subways/Tunnels, elevators, 2G/3G, and sudden disconnects.
- **🛑 Live Breakpoints & Interception**: Pause outgoing API calls, edit JSON headers & bodies on the fly, and forward or drop them.
- **📊 Real-time Waterfall**: Inspect status codes, latency timelines, headers, payloads, and copy as cURL.
- **📱 Modern Desktop UI**: Sleek dark-mode dashboard connected via high-speed WebSockets.

---

## 📁 Repository Structure

- `packages/lintron`: Client npm library for React Native and Expo.
- `apps/desktop`: Electron dashboard and WebSocket control server.
